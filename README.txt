RAIZ LOCAL TOLIMÁN — PROTOTIPO PHP
Instalación:
1. Copia esta carpeta a C:\xampp\htdocs\RaizLocalToliman
2. Inicia Apache en XAMPP.
3. Abre http://localhost/RaizLocalToliman/index.php

Páginas:
index.php portada; acceso.php selector de perfil; cliente.php catálogo;
vendedor.php panel para publicar/editar/eliminar; perfil.php edición de perfil.
Logo propio: assets/img/raiz-logo.svg.

El prototipo no tiene base de datos ni autenticación real. Publicaciones,
favoritos y perfiles se guardan en localStorage del navegador. Los nombres,
precios y métricas son ficticios. La carga de imágenes y WhatsApp quedan
como puntos de integración para el equipo.
Integración prevista: Lupita conecta base de datos/Firebase y carga de fotos;
Lili conecta autenticación, perfiles reales y WhatsApp; Daniel mantiene portada,
catálogo y diseño visual.
